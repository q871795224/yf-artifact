# Artifact Classic商店：三个货源与购买流程

**本作适用状态（D82，2026-11-18）**：用户明确当前Demo仍每3回合发1张物品牌，不引入本页商店货源。依用户要求持久化本资料，留待后续升级装备功能参考；本页不作为当前发牌或支付流程的规格。

核对日期：2026-11-18。仅解释Classic，避免混入2020年Foundry商店重做。后者曾把三个槽位统一为混合物品牌堆并引入等级／升级，不是当前要参考的Classic三货源。

## 三个并列商店位

原版每轮完成三路后购物，双方各自购买。不是每轮强制“三选一”：可不买，也可在不同商店位分别购买；自带物品牌库位买后立即补货，因此可同轮连续买多件。

| 位置 | 货源 | 购买与刷新 |
| --- | --- | --- |
| 左：神秘商店 | 游戏全局可供神秘商店出售的物品池；不受自带物品牌库限制 | 每轮随机一件；买后本轮不继续补货。可花1金保留未买物品到下一轮 |
| 中：自带物品牌库 | 玩家对局前构筑的物品牌库，至少9张，同名最多3张 | 显示其中一件，买后立即补出剩余牌库中的下一件；有钱可继续买；买完牌库不再提供该货源 |
| 右：基础消耗品商店 | 治疗药膏、泉水烧瓶、知识魔药、回城卷轴四种中的随机一种 | 本轮一件，购买后等待下一轮刷新；不消耗自带物品牌库 |

基础四种消耗品不放进自带物品牌库，也不在左侧随机池。其他消耗性物品，例如金奖券、抹灭法球，以及特殊的商店契约，可来自神秘商店／构筑。部分简略指南写“神秘商店不含消耗品”不够精确，应区分基础四种与其他一次性物品。

物品购买时支付金币进入手牌，之后行动阶段使用／穿戴，不重复支付金币，也不花法力或要求英雄颜色。Classic没有要求先合成低阶装备才能购买高阶装备的通用配方系统；高级装备可以构筑进物品牌库，也可能在神秘商店出现。此处不是本作已经决定采用商店。

## 来源与核对范围

- [Swim，Artifact Guide Part 1，2018-11-28](https://steelseries.com/blog/artifact-blog-77)：三货源、1金保留、物品牌库位即时补货、基础四种消耗品，以及购物阶段位置。
- [Items资料页](https://artifact.fandom.com/wiki/Items)：基础四种消耗品与普通消耗品的货源区别，每轮随机一种基础消耗品。
- [Decks资料页](https://artifact.fandom.com/wiki/Decks)：物品牌库至少9张、同名最多3张。
- [PCGamesN当年玩法指南](https://www.pcgamesn.com/artifact/how-to-play-artifact)：物品牌库购买后的补货与买空停止，消耗品不构筑的说明。
- [2019年玩家实玩记录](https://kmcfadyen.com/blog/page/14/)中2019-01-17的Artifact文章：左／右商店当轮买完不补货，与中间立即补货的区别。
- [本地客户端术语表](../../references/artifact-classic/glossary-english.json)：购物在回合之间进行，Gold Cost说明购买时付金币、打出不再支付。
