# Classic红绿法术完整参考

整理于2026-11-18。来自本地2018-12-22 Valve API快照，不是Foundry，不冒充Classic最终平衡版；不混入本作改编。用户要求先看原版，然后由用户提出模型、设计卡牌，再共同提炼属性价值。本页不替用户预先定法术模型。

**共57张：红色普通20张、红色专属10张、绿色普通19张、绿色专属8张。** 仅列Spell；单位、英雄技能、物品、建筑改良不混入法术。英雄专属中为单位的3张绿色卡已在单位参考中列出，不在本页重复。

## 原版术语与阅读边界

- 卡文“修改”表示永久修改，“在本回合”与“直至下个战斗阶段结束”等时限按原文保留。
- 未标跨线的单位群体效果按原版当前兵线理解；明确任意兵线／选择兵线的效果保留跨线资格，不自动改成本作全棋盘。
- 友方近邻是左右直接相邻单位；敌方近邻是面前最近的三个敌方战斗位置，不对应本作四邻／八邻。
- “强化”在这些卡文中指建筑改良Improvement，不是泛指buff；惩处强化即移除相应改良。
- 透甲表示伤害无视护甲；顺势是原版Cleave。原版攻城是受阻挡时仍对敌塔造成伤害，与本作直接打塔加伤不同。
- 获得先手表示下一个行动仍由自己执行，不是抽牌。
- 原版“战斗”效果直接进行卡文指定的交战，不能当成本作一轮锁定仇恨；原版决斗、吼、神之力量等与本作已经确定的改编不同。
- 净化移除指定方施加的修改／暂时效果，不治疗伤害，不直接移除装备或外部光环。

以下保留原始简中卡文；未用本作的“魔法／分裂”等名称覆盖来源文本。

- 触发陷阱：两名半人马猎者，各4攻击／0护甲／8生命；法术简中写“半人马猎手”，关联单位的规范名为“半人马猎者”。
- 绽放防御：两道玫叶墙，各0攻击／0护甲／8生命。
- 原始卡文“英雄”“单位”“小兵”“红色英雄”“绿色英雄”等目标限制不可互换；本作若改需另记。
