## 找图与恢复

本机素材集中在 `output/dota-lore-references/`。`index.html` 可点开官方选页和客户端对话图，`first-ten-unit-directions.html` 对照首批 10 个方向，`user-reference-handover/01.png` 至 `12.png` 保存用户选图。`output/` 被 Git 忽略，新 checkout 需要带上这批本地素材。用功能描述和编号检索时也可以先看 `panels-preview.png` 和 `portraits-preview.png`。

1. 官方网页先打开漫画阅读器，翻到要找的画面，再从页面 `<img>` 的 `currentSrc` 或网络请求抄下 Valve CDN 地址。最初保存的网页 HTML 主要是站点外壳。已有 `check-panels.js` 和 `official-panel-urls.txt` 记录了运行时取图方式和部分直接地址。文件编号跟随阅读器进度，`000` 常是封面，`#p=4` 也可能在第 3 步的画面上追加一格。收到的图要实际打开确认。
2. 对话图优先查已有客户端索引 `dota-vpk-index.txt`。重点目录是 `panorama/images/events/crownfall/visual_novel/portraits/`、`panorama/images/events/dark_carnival/visual_novel/portraits/` 和 `panorama/images/comics/tipofthespear/`。首选 `idle` 或 `neutral`。既有导出是从 Steam 完整 Dota 客户端的 `game/dota/pak01_dir.vpk` 用 Source 2 Viewer CLI 按 `.vtex_c` 路径提取的。PNG 已解包到 `client/panorama/images/`，`portraits.tar` 也留在本机。缓存足够继续整理。
3. 新线索优先查《大屿前来》的渡口与舟队、《战矛尖锋》的军阵与军阶、《暗黑狂欢》的巡场与水岸配角。客户端索引还有未纳入本轮选图的 `candlemaker`、`clown` 和 `witch_keen`。先记录实际页码或资源路径、角色在图中的位置，以及独立立绘能确认的部分，再写原创岗位。

## 卡图上怎么用

- 漫画用来找族群、阶层、职业和生活环境。对话立绘能补喙形、脸部、衣料和持物。裁漫画时只保留需要观察的局部，气泡、分镜边界和相邻角色留在原页。给生成模型的改写目标是原创角色、不同服装器物和独立构图。
- Classic 无框原画只需说明观察目的，例如亮天空托出旗帜、宽暗面压住背景、局部硬边强调脸和手。已有试跑里，黑色法术同时用两张同题材无框原画，比蓝色法术混用自制图更接近目标笔触。红卡使用同款熔岩和橙红边光时，小卡的色块容易混成一片。十张旧英雄题材概念的前六张也出现偏暖底色聚集。 [卡牌插画工作流](../development/card-art-workflow.md) · [英雄题材概念小图](../../assets/migoo/dota-hero-role-concepts/small-preview.png)
- 每张先定一眼能看到的岗位动作，再定视角、光源方向、阴影形状和主色。举例来说，渡工可以在上方斜看、靠浅水反光提亮蹼足。检修偶可以贴地侧看，只让工具箱顶部吃到窄暖光。步卒可以平视站在浅色天空前，用矛和人身拉出两个竖向轮廓。最后按 9:16 无框纯插画验收，缩到约 48 像素宽并排比轮廓、器物和大色块。
