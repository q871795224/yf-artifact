# Classic 红绿单位完整对照表

整理于2026-11-18。用户要求先看原版完整单位再讨论，不推进此前助手拟定的红绿白板新卡。数值来自本地 **2018-12-22 Valve API快照**，不混入本作改编或Foundry版本，也不冒充Classic最终平衡数据。

共31条：**红色普通13张、绿色普通12张、英雄专属单位3张、召唤物3种**。表中攻击／护甲省略字段按0显示；来源原件不改。面板顺序统一为攻击／护甲／生命。

原版“修改”在此简写为永久加减属性；“本回合”效果会另注明。原版近邻指兵线中的左右邻位，不能直接当成本作八邻；未写跨线的友方单位效果按原版所在兵线语境阅读。原版透甲对应本作魔法伤害，顺势对应本作分裂，卡文仍按原版含义保留。

**重要边界**：原版攻城是在被阻挡时仍伤塔，本作已定义为直接普攻塔加伤；本页雷肤兽群保留原版攻城，不将本作定义套回参考卡。原版费用与攻血分布只供参考，不据此推翻已定白板／护甲预算。

先对照原版单位的费用、身材和能力构成，再挑希望借用的单位身份或简单效果，按本作已定预算重新设计。此前助手给出的红色偏攻／绿色偏血白板表保留为未采纳草稿，本轮不继续扩卡。
