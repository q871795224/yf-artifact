# 普通卡池建模：Classic 原版参考

整理于 2026-11-18。用户要求先看原版卡牌、抽牌与装备经济，再讨论本作基础牌模型，最后才设计具体普通卡池。**本页是参考材料，不确认新卡牌、起手、抽牌或装备经济方案，也不改引擎。**

## 版本与来源

- 卡牌数值来自本地 Valve API **2018-12-22 Classic 快照**，见[参考库来源说明](../../references/artifact-classic/README.md)。不冒充最终平衡版本，不混用 Foundry 数据。
- 原版起手、抽牌、构筑与商店另查当年规则指南；本作是三英雄单路、1 法力起步，并新增英雄等级和重铸，不能将原版三路资源与牌库比例直接照搬。

## 起手、抽牌与金币经济

- Classic **起手5张，此后每轮抽2张**；每路独立法力池首轮3点，每轮上限+1并刷新。每轮抽2是整个玩家共享的抽牌，不是每路抽2。见 [Game Informer 当年试玩说明](https://gameinformer.com/games/artifact/b/pc/archive/2018/03/09/how-do-you-play-it-and-how-will-you-pay-for-it.aspx) 与 [规则指南索引](https://artifact.fandom.com/wiki/How_to_Play_Guide_for_Artifact%3A_The_Dota_Card_Game)。后者正文抓取受robots限制，起手与抽牌依据搜索索引，并由前者交叉核对。
- 普通牌库通常按最低 **40张**构筑，其中五名英雄带来 **15张专属**，其余可选25张；同名普通卡最多3张。物品牌库另带，至少9张。见 [构筑规则](https://artifact.fandom.com/wiki/Decks)、[当年40张含15专属的构筑说明](https://www.millenium.org/guide/317598.html)。这些规模不直接成为本作三英雄的牌库规模。
- 原版默认小兵死亡赏金1金、英雄死亡5金；不要求英雄亲自补刀，见[机制说明](https://artifact.fandom.com/wiki/Mechanics)与[本地原版规则核对](classic-foundry.md)。常规无每轮工资；特殊卡仍可额外产金。
- 完成三路后进入购物，有秘密商店、自带物品牌库、基础消耗品三个货源；自带物品牌库买完一件会立即补出下一件，不是每轮只能买一件。见 [Swim 的原版入门指南](https://steelseries.com/blog/artifact-blog-77)。

## 对本作模型的讨论顺序（仅建议）

先只决定基础效果预算，不马上扩成一整套具体牌：

1. **即时伤害**：已有认可锚点1费2伤害，仍须明确物理／魔法、英雄／小兵／建筑目标与施法范围。
2. **当轮加攻与治疗**：参考原版临时强化较便宜的关系，结合本作一级英雄血量决定数值；不自动将1费+4攻或3金治疗6换算成本作法力牌。
3. **永久强化**：与临时强化分开估值，计入英雄返场保留、可反复造成收益等因素。
4. **基础单位**：已有普通兵2／0／4和低费白板估值讨论；当前专属灵狼2费两只1／0／3、3费两只2／0／3、4费两只3／0／3均已定。普通召唤要与这些本作锚点比较，但不以攻血简单求和定价，数量、光环、占位都改变价值。
5. **供给与金币**：待上述费用曲线成形后，再定起手几张、每轮几抽、牌库总量及装备价格／来源。起手或抽牌多，不代表首轮法力也足以花完；重铸只改善选牌，不增加手牌数量。

本页没有确定本作新的普通卡池。英雄相关结论继续以[英雄总表](../design/hero-final-review.md)为准。
