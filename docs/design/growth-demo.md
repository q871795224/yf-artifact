# 成长 Demo：讨论结论与英雄草案

更新：2026-11-17。用于接续本轮设计讨论，尚未实现或发布，也未指定新版本号。当前可玩规则仍见 [V0.3 规则现状](current-rules.md)。

状态约定：**已确认方向**可作为后续设计前提；**用户提出的候选**保留原始意图和数值，不代表平衡或细则已定；**建议／待讨论**尚未获得确认。本轮用户明确要求先对齐英雄，不着急实现。

## 为什么调整方向

用户试玩 V0.3 后感觉不到乐趣，随后提出两个主要假设：

1. 缺少渐进过程。开局英雄能力已基本完整，同时出现多名英雄、小兵与陌生手牌，信息负担较大；后续缺少从弱到强、逐步获得更多手段的体验。
2. 现有卡牌可能过于复杂。考虑围绕本作地图和交互自研简单、容易理解和使用的牌，不继续把原版体系当作必须沿用的约束。

用户认为收益兑现目前还好，因此不将“反馈兑现太慢”列为当前已确认的问题。原版是否不平衡、成长是否能解决乐趣问题，均没有结论；自动对局能结束、浏览器操作通过，也不等于真人体验成立。

接下来优先观察：开局能否理解少量选择、中期能否形成配合、后期能否感到队伍成长并期待下一次能力变化。

### 成长细则：2026-11-18 已确认

用户明确本意是**按经验值升级**（补刀／击杀单位获得对应经验），好处是**经验值可被卡牌与英雄调节**：可以出加速经验获取的卡、英雄，或直接给经验的卡，等于多一个控制力度。第一期 Demo 认为这套太复杂，先只跑通核心，改用**回合经验值**作为等价替身——将来只需替换经验的**获取来源**，等级阈值与生效逻辑不必重写。

| 项目 | 已确认结论 |
| --- | --- |
| 获取 | 每回合结束时英雄**在场且存活**，+1 点「回合经验值」；泉水内算、返场当轮算；当轮末已阵亡不加，缺席／等待返场期间不累计 |
| 阈值 | 累计 **3 点升 Lv2、6 点升 Lv3**（即各需 3 回合）。此前「每两轮升一级」只是建议，已废弃 |
| 进度与等级 | **死亡不掉级、已累计进度不清零**；阵亡期间不累计，返场后继续 |
| 生命上限 | 上限涨几点，**当前生命直接加几点**，不按比例换算；不把升级当回满血。例：4／6 升到 4／8 时变 6／8 |
| 生效时机 | **已确认：回合末累计并判定，下一回合开始生效**（与现有「回合开始处理冷却／清除效果／返场／出兵／资源」同一批结算）；交战已结束，不追溯改本回合结果 |

按已同意试验的开局节奏（前三轮每轮登场一个英雄），3／3 阈值会让三位英雄的 Lv2 分别落在第 4／5／6 轮、Lv3 落在第 7／8／9 轮，天然错开，与「三级＝三个强势期」吻合。

**仍待确认**：泉水挂机升级是否影响体验（用户确认「没问题」，先照此实现，仅列为真人试玩观察项）；升级与生命上限变化在返场当轮、同轮致死等边界的结算顺序；红方／绿方纯色对局下的颜色封锁、卡池供给与双方强度差异。

经验阶段保留用户的后续思路：只有英雄获得经验，多名英雄参与同一击杀时平分经验。用户补充：经验值应能被卡牌与英雄加速或直接给予，作为额外的调节维度；经验总量、参与资格、纯小兵击杀的分配方式、加经验卡的费用与供给等尚未设计；没有采用「击杀经验分给全队所有英雄」的规则。

## 数值模型：锚点与候选

面板顺序统一为 **攻击／护甲／生命**。

| 项目 | 数值 | 状态 |
| --- | --- | --- |
| 基础近战小兵 | 2／0／4 | 用户认可的锚点，现有基础兵也为此数值 |
| 简单伤害牌 | 1 费造成 2 点伤害 | 用户认可的锚点；伤害类型／射程等仍需定义 |
| 普通一级英雄 | 3／0／6 | 用户提出的模板候选，依定位浮动 |
| 普通二级英雄 | 4／0／8 | 助手补充的中间模板，待确认 |
| 普通三级英雄 | 5／0／10 | 用户提出的满级模板候选，依定位浮动 |
| 无技能单位卡 | 2 费对应 2／0／4，进一步考虑 1 费对应 1／0／2 | 用户提出的身材估值起点，尚未成为通用公式 |

用户认为此前 3／0／8 到 5／0／14 的模板可能过厚，希望一级更弱、等级差距明显，同时满级也不要膨胀过大。具体英雄可以偏离模板，能力与装备需要计入总强度。

用于讨论的静态关系，均忽略装备、能力、治疗等：

- 3 攻攻击 10 血需要四次，5 攻攻击 6 血需要两次。3／0／6 到 5／0／10 已存在跨级差距，并不需要靠大幅增加生命才能体现成长。
- 属性不能简单线性折算为费用。单位能持续攻击、占位、接受强化，伤害牌则立即生效；2 费 2／0／4 不证明其他无技能单位必须按同一比例设计。
- 以下护甲样例采用当前普通伤害 `max(伤害－护甲, 0)`。新卡牌的普通／透甲区分尚未确定。

## 斧王：高属性，自身无技能

**用户提出的候选：**

| 等级 | 面板 | 自身能力 |
| --- | --- | --- |
| 一级 | 3／0／5 | 无 |
| 二级 | 4／1／8 | 无 |
| 三级 | 6／2／10 | 无 |

沿用原版高属性、弱技能／自身白板的方向，三级面板取旧参考值。拥有专属卡 **狂战士之吼**，希望影响周围八格敌方单位；解锁等级、费用、获取方式尚未确定。

**2026-11-18 用户已定：引入「嘲讽」词条，取第 2 种结算。** 正常交战阶段结算，斧王**不**因此多打任何人；影响范围为**周围八格（含斜角）**，受影响单位的**仇恨锁定到斧王，优先级最高且不可更改**。若因斜角导致四正向普攻不合法，该单位会**主动移动去填四正向空格**以尝试攻击，而不是原地放弃。

底层原理是「锁定仇恨」而非「临时改箭头」：八格是**施加范围**，四正向是**实际攻击的合法性**，两者不冲突。这也意味着本作现有「不因索敌而自动追击」的规则需要为嘲讽新增例外，且多单位填格需复用现有同格争抢规则。

**2026-11-18 最终确认：**

- **持续：当轮有效**（一轮内含多个交替行动，整个这一轮生效）。决斗同为当轮有效，轮内有人死亡则提前结束。
- **被锁定单位不允许手动移动**；若该单位本回合**尚未移动过**，则在**回合结束后自动移动**追向锁定目标以达成合法攻击，远程单位也会主动前压；已移动过的不再自动移动。
- **狂战士之吼无可选目标**，直接使用，影响**周围一圈八格内所有敌方单位（含小兵）**；**决斗**需选目标，**只限敌方英雄、周围四格**。用户本轮「决斗和嘲讽都只限英雄」的表述随即澄清为嘲讽无可选目标、是范围效果，故该限制只落在决斗目标上。
- 反伤**必须实际掉血**才触发；决斗胜者的永久 +1 攻**跨阵亡保留**。

**实现时需定死的时序**：锁定为「当轮有效」，但自动移动发生在回合结束后；移动后锁定是否仍作用到该次交战、下回合何时解除，需在写结算顺序时明确，不在此处推断。填格冲突复用现有同格争抢规则；保护转火与嘲讽的优先级另定。

### 护甲带来的强度变化

仅考虑一只 2 攻小兵持续普攻、不治疗、不升级：

| 斧王等级 | 小兵每次造成的伤害 | 满血到阵亡所需攻击次数 |
| --- | --- | --- |
| 一级 | 2 | 3 |
| 二级 | 1 | 8 |
| 三级 | 0 | 无法单靠该普攻击杀 |

这是候选面板的关键变化，不表示数值已平衡。三级可成为抗普通兵线的定位，但绿色阵容和通用卡需要有合理应对。

一级斧王与一级军团相同，且比普通 3／0／6 模板少 1 血。是否接受二级才分化，或把斧王一级改为 3／0／6，仍待确认；不能把后一个建议写成用户已选数值。

## 军团指挥官：反伤与单挑

**用户提出的候选：**

| 等级 | 面板 | 能力／专属卡 |
| --- | --- | --- |
| 一级 | 3／0／5 | 尚无反伤 |
| 二级 | 4／0／7 | 获得被动：受到伤害时造成 2 点普通反伤，受对方护甲减免 |
| 三级 | 6／1／8 | 保留反伤，加入专属卡“决斗”，类似单体的狂战士之吼 |

三级面板取旧参考值。用户指出其强制交战方向可能和斧王重复，因此两张专属卡需要一起讨论。

**2026-11-18 用户已定：反伤按「受到普攻」触发**，用户明确撤回此前口语里的「受到伤害」，也不采用「受到物理伤害」；以原版 Artifact 为准。是否要求「实际损失生命」才触发（伤害被护甲减到 0 时反不反）尚待一句话确认。

**决斗重新定义：** 不做原版「一定时间内反复互相攻击」。决斗是**变相的双向嘲讽**——双方仇恨都指向对方，优先级最高、不可更改，正常交战阶段结算；仍受其他状态影响（例如被眩晕就无法攻击）。**决斗中一方死亡时，另一方为胜利者，永久 +1 攻击力**；按现有规则，永久成长在阵亡返场后保留。

**2026-11-18 最终确认**：决斗**当轮有效**（「算一整场」指这一整轮，不是整局对局），轮内一方死亡则提前结束；目标**只限敌方英雄、周围四格**；反伤**必须实际掉血**才触发；胜者 +1 攻**跨阵亡保留**。被锁定单位不允许手动移动，本回合未移动过的在回合结束后自动追击，规则与嘲讽共用（见斧王节）。嘲讽与决斗共用的「锁定仇恨」底层词条为助手提出的抽象建议，用户未单独确认，保留为建议。费用与卡牌供给仍未定。

## 斯温：下一个待对齐的红色英雄

原色为红，旧参考面板为 5／0／11；既有顺势适配为攻击主目标时，伤害主目标两侧、垂直于攻击方向的敌人，不伤建筑，详见 [早期英雄草案](heroes-draft.md)。

助手提出的成长例子是 3／0／6 → 4／0／8 → 5／0／11，一级无顺势、二级弱顺势、三级强化。**用户尚未确认这些面板或能力节点**，顺势伤害、专属卡均未确定。

供讨论的三人分工：斧王抗集火／保护，军团反伤／单挑，斯温范围进攻／清兵。定位本身仍需结合完整英雄方案验证。

## 保留为建议、尚未采用的其他方案

- 三级成长的一般思路是一级体现身份、二级增加配合、三级强化已有玩法；不是所有英雄必须一级有技能或二级解锁专属卡，斧王白板与军团三级专属均是用户的新候选。**（2026-11-18 注：本条已被「三级 = 三个强势期」取代，不再作为评估标准，见下方名单对齐结果。）**
- 每色六张通用牌、其中四张为 1～2 费；每英雄一张专属；升级定向发专属卡；装备固定商店可购买。这些均为助手建议，具体卡池、供给与经济尚未敲定。
- 不默认增加工资、调整赏金、改法力轨道、加入跳刀连招、手动普攻或即时战斗通则。
- 成长、属性和专属卡改变后，塔／基地数值、治疗、护甲与装备仍需重新校准，不能直接宣称旧平衡适用。

## 名单对齐结果（2026-11-18）

用户已确认第一期名单与两条设计原则，完整结论见[第一期英雄对齐结论](hero-roster-alignment.md)（本轮唯一结论页）：

- 规模维持**红、绿各三位共 6 人**：红色斧王／军团指挥官／斯温，绿色狼人／陈／树精卫士（大树）。魅惑魔女保留为候选，不进第一期。
- 与另一个 AI 讨论出的四色 10 人方案，除斯温、狼人、陈、大树外，其余**蓝色三位（宙斯／露娜／撼地者）与黑色三位（狙击手／莱恩／NEC）作为第二期备选**，不进第一期；本页的红绿范围、D30 的撼地者暂缓继续有效。方向偏「还原原版」不视为问题，第二期内容针对本作单路地图做针对性适配即可。
- **三级 = 三个强势期**：用户明确某级能力不变是正常的，表示该英雄强势期在前面，不要求每位英雄逐级新增能力文本。**本页「三级成长的一般思路」及助手上一轮「逐位补出能力变化」的建议撤回**，改用三级曲线整体评估；但 Lv1 偏薄的英雄要能活到自己的强势期，留给成长阈值验证。
- 复杂效果倾向抽成**基础关键字**复用，而不是逐位写特例；已有引擎词条可直接承载，具体词条表待定。跳费、追溯、妖术、延后登场等一次性特例整体后置。

以上只确认名单与原则。斧王吼、军团反伤／决斗、斯温顺势、六位的具体面板与专属卡、成长阈值与结算细则均未收口，也未开始实现。
