## 对局、回合与行动

1. 第一回合双方各两名英雄、两只原版近战兵直接部署中线两侧，双方对位列组合相同，具体列随种子变化，保证首轮可接战。第三名英雄第二回合在泉水出现。
2. 回合开始处理冷却、清除上一轮眩晕／临时效果、英雄返场、出兵、资源与抽牌，然后小兵自动行军、公开目标，进入行动阶段。
3. 每轮都有行动和交战，不插入全局纯行军轮。奇数轮我方先手，偶数轮 AI 先手；AI 先手会先执行一次回应再交还操作。
4. 移动英雄、施放普通牌、主动技能、穿戴／使用物品均占一次行动，之后对方回应。取消选目标不占行动。
5. 双方连续让过触发交战；任何有效行动都会打断连续让过。普攻以交战快照汇总结算，不按画面播放顺序轮流扣血。
6. 交战后停留在结果状态；“下一回合”只是继续播放的入口，不额外消耗行动。基地被摧毁或认输后结束对局；没有正式的强制轮数上限或超时判胜。

## 地图、移动与容量

代码坐标为排 `0…7`、列 `0…4`；界面使用第 1～8 排、第 1～5 列。我方泉水在排 7，敌方在排 0。塔／基地位于本方泉水与最近一排战场之间，不占格，不限制通行。

- 每格最多一个单位，双方可越过中线、绕塔或进入敌泉。单位上限 24 是每方的原型限制，与全棋盘 40 格分别检查；不能把 40 格理解成每方可放 40 个单位。
- 英雄每轮移动一次，普通移动八邻一格，包含斜向、侧向和后方；不额外花法力或金币。出生／返场后的首次移动最多两个合法子步，不穿过占位，返回泉水不重置首次移动机会。首轮前线部署不再享有这次两格机会。
- 小兵自动向前，有四向可近战的相邻敌人时停留；被挡时尝试一格侧前，不横跨两列或瞬移前线。新兵首次可走两步，每步重算占位。
- 自动移动先生成意图、处理同格争抢，再检查跟进依赖。允许跟进己方本批刚腾出的格子；冲突用可复现随机结果选择成功者，其他留原位，不因遍历左右或阵营顺序偏置。
- 第二回合起每方每轮尝试在泉水出两只近战兵，原版面板为 2 攻／0 甲／4 血。当前自动兵只有近战；随机因素主要是出生位置，没有实现随机近战／远程组合。
- 普通新增单位遇到上限／出生区无位时少出或不出。卡牌召唤使用己方泉水空位或己方英雄八邻空位；一次召唤多只时位置不足只生成可容纳部分。

## 目标、伤害与建筑

- 近战普攻四正向一格，远程四正向两格以内；移动的八邻范围不等于攻击范围。一次普攻一个主目标，溅射、反伤和装备效果另行结算。
- 自动索敌保持仍合法的旧目标，失效后选四向射程内最近敌人，同距离按稳定单位 ID 决定。没有合法单位目标才考虑建筑；不因索敌而自动追击。
- 箭头常态显示攻击意图，金色我方、蓝色敌方，远程虚线指向实际目标。它们是当前状态的预览，对手后续行动可能改变目标。
- V0.2 允许远程隔单位攻击合法敌人；单位不阻挡对建筑的攻击。建筑用共享一线、跨整条线宽的排距模型：塔位置为 `0.5／6.5`，单位是否可打建筑按排距与自身射程判断；建筑攻击范围按排距不超过两格判断。
- 保护英雄转火开启，作用于小兵和建筑，英雄自己仍按常规仇恨。观察敌方英雄当前普攻意图是否指向友方英雄；小兵需要八邻感知且四向射程实际可打，塔需要自身范围可打。斜角感知但打不到就忽略，不扩大射程或追击；法术／技能不触发这条保护逻辑。
- 普通伤害按 `max(伤害－护甲, 0)`，透甲伤害直接扣血。交战汇总伤害、恢复与死亡清理；当前恢复先于死亡清理，可抵消部分同轮致死伤害，处决类效果另外处理。这是现有实现，不把动画先后理解为先攻击者获利。
- 破塔后同位置出现基地，无过量伤害转移；基地下一回合才可受伤和攻击。没有额外破塔金币、全队强化或自动强化兵补偿。摧毁基地获胜，双方基地同轮摧毁为平局。
- 泉水与基地分开：泉水每次交战对本泉水排的全部敌方入侵者造成 10 点普通伤害，不是全图攻击；不自动治疗、刷新 CD、提供无敌或阻挡入侵。

## 英雄、死亡与颜色

候选为红／蓝／绿／黑四色，每色三名。颜色定位是红色正面作战、蓝色法术控制、绿色友军强化／召唤、黑色爆发与机动；定位不意味着已经新增对应特殊移动规则。基础面板取本地原作快照，细表见[英雄草案](heroes-draft.md)。

正式试玩固定我方斧王／撼地者／狼人，AI 军团／冰女／幻刺。默认开局种子生成方式保持我方斧王、撼地者首发，狼人第二轮入场；指定测试种子可能改变英雄部署轮换。其他候选有引擎能力实现，但没有开放阵容选择入口。

| 颜色 | 候选英雄 | 当前能力要点 |
| --- | --- | --- |
| 红 | 斧王／军团／斯温 | 白板身材；受到普攻固定反伤 2（减免前）；普攻主目标两侧溅射自身攻击一半、向下取整 |
| 蓝 | 宙斯／冰女／撼地者 | 蓝色法术触发八邻 1 透甲；每轮首次己方法术恢复 2 法力且不超过上限；八向选一直线两格，各 2 普通伤害并眩晕，CD 4 |
| 绿 | 陈／狼人／魅惑魔女 | 两圈内控制非英雄、CD 4；八邻友军 +2 攻、不含自身；自身及八邻友军 +2 恢复 |
| 黑 | 赏金／幻刺／莱恩 | 每轮预先公开 50% 概率 +4 攻；普攻英雄额外 4 伤害；两圈内 8 透甲，首次施放后 CD 4，后续 3／2／1，最低 1 |

“两圈”按横纵坐标差的最大值不超过 2 判断。主动技能不花法力／金币，通过冷却与行动限制；每轮开始 CD 减一，阵亡期间继续计时。当前英雄技能初始可用，莱恩的“首次 CD 4”指首次施放后的冷却，不是登场先等四轮；现有界面简称容易误读，后续开放候选时需统一措辞。

眩晕持续到下一轮开始，禁止移动、普攻、主动技能和装备主动；存活英雄仍提供颜色，现有被动／光环继续按代码结算，眩晕英雄仍可成为穿戴或消耗品的合法目标。沟壑第一格空或为友军不阻断第二格，零伤害仍能眩晕。

英雄在第 N 轮死亡，N+1 轮缺席，N+2 轮尝试满血返场；装备与已有永久成长保留。英雄返场先于普通新兵：优先泉水空格，泉水被己方小兵占满时替换低生命小兵并正常发赏金；不能替换英雄／敌人，无可用位置可继续等待。达到队伍上限时也需先腾出己方非英雄容量。

普通牌需要有对应颜色的存活在场英雄；在泉水或眩晕仍算在场，阵亡不提供颜色。失去所有颜色不等于不能让过或推进回合。

## 双经济、牌库与装备

| 项目 | V0.2 原型基线 |
| --- | --- |
| 法力 | 首轮 1，逐轮增加，最高 10；每轮刷新当前可用法力 |
| 金币 | 初始 0，跨轮累计；无工资，敌方非英雄死亡 +1、英雄死亡 +5，包含召唤物与返场替换牺牲 |
| 普通牌库 | 每队 36 张；每名英雄贡献其颜色六种普通牌各两张，同色英雄增加重复数；起手 5，每轮后续抽 2 |
| 物品牌库 | 每队 18 张，独立于普通牌库；开局 1，此后第 3／6／9…轮各 1，无额外购物阶段 |
| 构筑／商店 | 当前固定牌库；三回合三选一、自由构筑均未做，不能将工作台预设视为构筑功能 |
| 空库 | 抽不到就不增加牌；未加疲劳或强制终局规则 |
| 装备 | 武器／护甲／饰品各一槽，同类替换；穿戴花金币；物品无色，不占普通牌法力 |
| 主动与消耗品 | 消耗品用后移除，装备主动受各自 CD 限制，各占一次行动；已穿装备的主动不再花金币或法力；金奖券生成的已付费物品不重复扣款 |

当前内容基于[扩展牌池](expanded-card-pool.md)加[终端适配](finisher-card-pool.md)。法力轨道保留胜利时刻、达摩克斯霹雳等终端；金币轨道将大剑／英雄披风位置换为 25 金封神之刃／领袖号角。两条轨道都应有把资源兑现成胜利的能力，不要求余额归零，也未统一削减所有防御属性。
