## 4. 新原则一：三级 = 三个强势期

**用户明确**：英雄分三级，意思是**他可能有三个强势期**——有的一级强势、有的二级强势、有的三级强势；**某一级能力没有变化是正常的，说明这个英雄的强势期在前面**。

由此：

- **撤回**上一轮对齐稿 3.5 节的判断，以及「逐位补出至少一级能力变化」的建议；它**不是**本项目的评估标准。
- 也**不再**把 growth-demo「一级体现身份／二级增加配合／三级强化已有玩法」这条（本就标为助手建议、尚未采用）当成硬性检查项。
- 评估方式改为看**三级曲线整体**：六个位置（红绿各 3 人 × 3 级）合起来是否形成错开的强势期，让不同回合有不同的英雄值得期待；而不是逐级检查有没有新增文本。
- **保留一条推论**：Lv1 偏薄的英雄（露娜 1／6、撼地者 1／5、宙斯 2／5 一类）如果要靠「回合末存活」累计升级，必须能活到自己的强势期，否则曲线不成立。这是**定成长阈值时要验证的事**，不是要求改能力。

## 5. 新原则二：复杂效果抽成基础关键字

用户提出「有些东西可以当成基本关键字」，并于 2026-11-18 重新命名了部分词条。核对现有引擎与文档后，**多数词条不需要从零新造**，只有「锁定仇恨」是新增的：

| 关键字 | 当前定义／出处 | 第一期可能用到 |
| --- | --- | --- |
| **物理伤害 / 魔法伤害** | 原「普通伤害／透甲伤害」：`max(伤害－护甲, 0)` ／ 无视护甲直接扣血 | 全部、专属卡 |
| **眩晕** | 禁移动、普攻、主动技能；不封颜色；下一轮开始解除 | 第二期撼地者／莱恩 |
| **分裂 N** | 原「顺势」。攻击主目标时，对两侧各一格造成**固定 N 点物理伤害**，不伤建筑；**不按攻击力比例计算** | 斯温 Lv1／Lv2／Lv3 固定为 1／2／2；装备加攻、神之力量不提高分裂数值（D44） |
| **反伤** | **受到普攻**时对攻击者造成固定 2 点物理伤害，受护甲减免；法术、反伤本身不触发 | 军团 |
| **光环（近邻 +N）** | 八邻友军加成，**不含自身**（按原版，见下） | 狼人 +攻；大树光环已随换人退出本期，守护天使是否含自身另定 |
| **召唤** | 灵狼按 D56 专门落点：狼人正四格优先、斜四格其次，八邻不够再向外按距离找空位；不另选泉水 | 狼人双灵狼；其他召唤物不能自动套用此专门规则 |
| **劝化／控制** | 两圈内控制一名敌方非英雄单位 | 陈 |
| **锁定仇恨（新增）** | 优先级最高、不可更改的仇恨指向；受影响单位会主动靠近以达成合法攻击。**嘲讽**＝八格内多对一单向；**决斗**＝一对一双向＋胜者永久 +1 攻 | 斧王吼、军团决斗 |

**复杂度真正的来源不是这些词条，而是新方案额外引入的 4 个一次性特例**：玫叶德鲁伊的临时／永久跳费（改法力轨道）、灵狼费用「手上是否追溯」、妖术新状态词、NEC「击杀延后一回合登场」。**建议这 4 个整体后置到第二期**，第一期所有能力都挂在关键字上。

**改名后的定义边界（待确认）**：物理／魔法建议按**结算方式**区分，与来源是普攻、技能还是被动无关。现有撼地者沟壑（技能）、军团反伤（被动）造成的都是受护甲减免的伤害，改名后即「物理伤害」；若不写死这一点，「技能造成物理伤害」容易被误读。

**光环按原版核对（已定）**：本地快照中狼人 `allied neighbors have +2 Attack`、树精卫士 `allied neighbors have +2 Armor` 都**不含自身**；只有魅惑魔女明确写了 `Enchantress has +2 Regeneration` **含自身**。她是候选、不进第一期，因此**第一期两个光环天然统一：都不含自身**。范围按用户定为**周围一圈八格**（狼人／小鹿／大树一致），试玩发现超模再调。

**建议的抽象**：嘲讽与决斗其实是同一套底层行为，抽成**「锁定仇恨」**一个词条，把「优先级最高／不可更改／主动靠近以达成合法攻击」只写一遍；嘲讽＝八格内多对一单向，决斗＝一对一双向＋胜者永久 +1 攻。注意这会为现有「不因索敌而自动追击」新增例外，且多单位填格需复用现有同格争抢规则。

方法论沿用文档原话：**先写清一个效果的完整行为，再把它抽成通用词条**。关键字表的持续时长、被锁定单位的移动边界、目标范围与反伤条件已于 2026-11-18 全部收口，见决策记录 D43。**第 ② 项完成**，下一步进入第 ③ 项逐位收口六人三级曲线。
