# 英雄批量推演：索敌实验

这是 8 轮战场实验，不包含推塔胜负；不能据此给颜色排强弱。规则、策略和测试假设见 [说明](README.md)。

## 覆盖

本批共 4800 局；20 个阵容两两有序配对，含镜像；每对 3 个环境种子，分别运行无牌与测试法术两种模式；索敌机制：arrows, aggro。

- 全部合法三英雄阵容：220（纯色 4，双色 108，三色 108）。
- 本批抽取 20：纯色 4、双色 12、三色 4；每位英雄恰好出现 5 次。
- 同一阵容轮换第三位英雄的入场选择；种子 11、12、13 覆盖三种延后入场选择。
