# 英雄批量推演 02：自动索敌与随机箭头对照

日期：2026-11-12。用户已同意采用“自动索敌＋保持目标”。本批实际运行新旧机制各 2,400 局，共 **4,800 局**，每局八轮。查看[完整报告](summary.md)、[机器可读汇总](comparison.json)，或直接观看[十个成对回放](replays.html)。

## 本次改动

- 所有英雄和小兵自动索敌。合法旧目标优先，即使出现更近的新敌人也不切换。
- 旧目标死亡、离开合法射程或变成友军时，选择最近的合法敌人；同距离按稳定单位 ID 排序，不依赖单位列表的遍历顺序。
- 近战仍为四正向一格，远程四正向两格；不增加斜向普攻。友军不阻挡远程攻击其他单位，沿用上一批测试假设。
- 自动移动结束后公开目标，每次实际行动和交战结束后刷新；目标跨回合保持，眩晕不清除合法锁定。
- 箭头显示实际攻击意图；无目标显示 `·`。回放同时显示自身和目标 ID，日志记录目标变化。
- 索敌不触发移动。英雄仍使用每轮一次的手动移动，小兵保持自动推进。
- 不累计伤害或治疗仇恨值，不增加自动追击、朝向操作或法力消耗。单位优先建筑的原则保留，但本批不模拟建筑，尚未验证其实际实现。

索敌查询是只读的，只有真实局面变化才提交锁定。AI 试算多个移动位置时不能改变锁定，避免评分污染对局。斯温的溅射方向依据实际主目标计算，与预览一致。

## 对照方法

沿用[第一批方法与测试假设](../hero-batch-01/README.md)：二十个阵容、同一有序配对、种子 11／12／13、八轮长度、相同英雄面板、同一 AI 评分权重，以及无牌／测试法术两种模式。每位英雄在抽样池出现五次，部署轮换覆盖三种延后入场选择。

唯一机制变量是 `targeting`：`arrows` 为旧随机箭头，`aggro` 为当前默认的自动索敌。每套为 20×20×3×2＝2,400 局。相同阵容、种子和法术模式的新旧结果组成一对。

出生、争格、赏金等使用独立事件随机流。改变索敌后，行动与伤亡会让后续局面分叉，所以同种子不保证后续位置相同。AI 会按当前机制评价目标，允许做出不同决定，但没有单独为某种机制调整评分。

旧目录完整保留。本次重跑的 2,400 局旧机制与第一批逐局核对，原有统计、金币、场上单位和英雄生命折算均完全一致，只增加机制标签。新机制检查全部无合法目标遗漏；保存的五个新机制回放逐帧核对目标合法性，以及合法旧目标没有被提前切换。

## 结果

以带测试法术的每套 1,200 局为例：

| 指标 | 随机箭头 | 自动索敌 |
| --- | ---: | ---: |
| 英雄实际普攻率 | 36.8% | 72.0% |
| 小兵实际普攻率 | 16.6% | 43.1% |
| 英雄有敌但方向落空 | 38.9% | 0.0% |
| 小兵有敌但方向落空 | 32.2% | 0.0% |
| 每队八轮英雄阵亡次数 | 1.76 | 2.77 |
| 每队八轮小兵阵亡次数 | 7.70 | 11.76 |
| 末轮每队场上单位数 | 10.90 | 6.59 |
| 每队八轮英雄移动次数 | 13.00 | 15.77 |

无牌模式也提高出手率：英雄从 34.6% 到 71.4%，小兵从 17.5% 到 49.8%；末轮场上单位从 12.56 到 6.75。

普攻率分母依然是交战开始时存活且未眩晕的单位×轮次；选到目标即算一次普攻，即使被护甲减到零伤害。技能、反伤和溅射不额外算普攻。

## 当前结论

1. 自动索敌消除了有合法敌人时的方向落空。零落空是机制预期与实现检查；普攻率、伤亡和末轮单位的变化才是观察到的连带影响。
2. 这批样本的交锋更密集，兵线积累减少。死亡赏金也随死亡增多，后续装备经济还需重新观察；这不证明铺场失效或最终战斗时长合适。
3. 英雄仍有大量移动选择。同一 AI 在新机制下执行更多移动，但不能代替实际玩家评价操作深度。
4. 新机制下，英雄仍有 28.0%、小兵有 56.9% 的机会没有四向射程内敌人，包含增援行军、斜向站位等情况。索敌不会自动解决这些空间问题。

本批不包含建筑、泉水伤害、装备或正式牌库，不判推塔胜负，不给颜色定最终强度。简单测试手牌仍无法充分评价冰女后期回蓝价值。建议接下来先人工看成对回放，观察近战接敌、远程站位与击杀节奏，再选择是否调整进场或伤害。

## 重跑

Python 3.10+，无第三方依赖：

```sh
# 新旧各 2,400 局，默认写入本目录
python3 scripts/simulate_heroes.py --targeting compare

# 单独测试当前机制，另设目录避免覆盖对照结果
python3 scripts/simulate_heroes.py --targeting aggro --out /tmp/artifact-aggro

# 单局回放
python3 scripts/simulate_heroes.py --a 10020,10054,10069 --b 10033,10064,10065 --seed 11 --probes --targeting aggro --out /tmp/artifact-aggro-replay

python3 -m unittest discover -s scripts -p 'test_*.py'
```

新增检查覆盖跨回合保持旧目标、死亡重选、最近优先和稳定同距顺序、AI 假想位置不改变锁定、脱离射程不自动追击、劝化后清除友军目标、斯温方向与预览、同时致死攻击。批量运行继续检查占格、生命、容量和行动终止。
