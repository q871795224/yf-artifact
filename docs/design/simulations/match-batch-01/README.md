# 完整对局实验 01：建筑、牌库与物品

日期：2026-11-12。卡池见[首批普通牌与物品](../../first-card-pool.md)，运行结果见[报告](summary.md)，可直接打开[九个回放](replays.html)。本批已从八轮场面实验扩展为摧毁基地获胜的完整流程实验。

## 用户已确定的方向

- 塔 40 血，摧毁后基地在**原塔相同位置**出现，基地 80 血。旧草案“基地在泉水后方”已被这次修正替代。
- 基地与塔一样单目标攻击，伤害为塔的两倍；不是六列全体攻击。泉水是独立设施，攻击侵入其范围的全部敌人。
- 塔无攻击和能一击杀死基础近战兵两种方向都测试；塔／基地伤害数值多次对照。
- 基础索敌和保护友方英雄的索敌分别测试。小兵八邻格感知到敌方英雄攻击友方英雄时，只有敌方英雄处于其合法四向普攻射程内才转火；斜角打不到就当无事发生，不追击、不记录额外目标。
- 物品牌池分消耗品／装备品，每类初中高三档、每档两种，共十二种。普通牌每色三种，共十二种，均选自本地原版快照，不含英雄专属卡。

## 本次实验的几何与结算假设

这些是用于跑通实验的明确假设，尚未将所有细则视为正式玩法定案。

- 沿用六列八排。A 泉水在底排，B 泉水在顶排；塔／基地分别位于本方第三排普通战场和泉水排之间，不占单位格。六列共享建筑生命，不挡路。
- 单位攻建筑的距离按所在行到建筑横线的距离计算：近战从敌方后排或敌方泉水排可以攻击，远程还能从敌方中排攻击。各列都可攻击共享建筑。合法单位目标始终优先于建筑。
- 塔和基地的索敌范围覆盖建筑横线两侧各两格内的六列；保持合法旧目标，无目标时选离建筑横线最近的敌人，同距离用稳定单位 ID 排序。每轮只攻击一次、一个目标，不按每列各开一炮。
- 泉水只攻击侵入本方泉水排的敌人，本次固定为每个目标 10 点普通伤害、受护甲减免；不附带回血、技能刷新或无敌。泉水伤害没有作为本批变量。
- 保护仇恨本次按**当前可见的敌方英雄普攻意图**判定，受眩晕而不能普攻的英雄不触发；法术和技能伤害暂不触发。保护目标优先于合法旧目标，但不增加攻击射程。触发后正常沿用合法目标保持，没有额外计时器。
- 同一个保护开关同时作用于小兵和建筑；塔攻击为零时，开关只会实际影响小兵。转火计数记录已非空的旧目标变化，可能含旧目标自然失效后的新锁定，不能当作严格因果次数。
- 单位、塔／基地和泉水使用同一战斗快照结算伤害，小鹿恢复后统一判死。塔被该次交战摧毁时仍能完成当次攻击；在出牌阶段已被摧毁则不能到交战阶段再攻击。
- 基地出现当轮不受伤、也不攻击，下轮启用。破塔过量伤害不转移，无额外破塔金币；蓝色“敌方塔伤害”牌之后可作用于同位置的基地，仍受当轮免伤限制。
- 一方基地归零立即获胜；同一交战双方基地同时归零判平局。达到 24 轮仍未结束记超时，不根据血量或场面强判赢家。

## 普通牌与装备如何接入

- 主牌库固定十八张：每名英雄贡献该颜色的三张普通牌、每张两份。因此纯色每种六份、双色主色每种四份／副色两份、三色每种两份。这是为了在极小卡池下保持队伍牌库长度相同，不是正式的重复卡上限或构筑规则。
- 起手五张，第一轮不额外抽牌；第二轮起每轮抽两张。空库不洗回、不疲劳、不判负，只停止抽牌。一般第八轮附近已抽完，所以这批对后期卡牌循环的覆盖有限。
- 十二种物品每队各一张，独立洗牌；开局一张，第三、六、九等轮各一张，抽完不补货。初始金币零，无工资；小兵（含卡牌召唤物）死亡赏金一，英雄五，金币跨轮保留。
- 每名英雄有武器／防具／饰品各一格；替换旧装备不退款，装备随英雄死亡保留。生命装增加等量当前和最大生命，换掉生命装时当前生命不超过新上限。
- 穿装备、使用消耗品各占一次行动，花金币，不花法力。普通牌花法力，英雄主动技能仍只受 CD 限制；双方行动交替。
- 物品无需颜色英雄提供颜色；装备只能穿给在场英雄，治疗可给在场单位。回城不治疗、不刷新技能或首次移动资格，也不重置当轮已移动标记。
- 金奖券从本次六件装备中等概率生成一张已支付费用的装备牌，穿戴仍占行动，不重复付生成装备的钱。抹灭法球只拆除一个建筑改良，不拆英雄装备。
- 发薪日是花三法力、使当前金币翻倍的普通法术，不是每轮固定工资；其增金与死亡赏金分开统计。每队都核对“赏金＋发薪日增金－消费＝剩余金币”。
- 卡牌单位与次元传送门可召唤到己方在场英雄八邻格或己方泉水空格，立即可参与本轮交战，下轮再自动移动。每方容量暂为二十四。多单位召唤至少有一个空位才允许使用，多余单位放不下则丢弃，不返还部分费用。
- 单路法术本次作用于相应阵营全战场；魔霭迷雾每轮在出牌前给己方在场单位永久加一攻击，不同副本叠加。萨特决斗家交战后存活则永久加二攻击。

## AI 与实验覆盖

复用已经验证的英雄、移动、技能、自动索敌，并在 [simulate_match.py](../../../../scripts/simulate_match.py) 扩展建筑、卡牌、物品和胜负。历史八轮实验代码与数据保留。

双方使用相同的确定性贪心策略。移动评分加入推进建筑与预见建筑伤害；防御牌、回城会计算单位、建筑和泉水的威胁。选择卡牌时考虑击杀、实际减伤、成长、召唤位置、建筑伤害和可消费金币；装备评价相对当前槽位的提升。没有多步搜索、协同强推或长期牌库规划，也不会像真人故意留关键牌。

沿用二十个抽样阵容，但本次只选三十六个有序对局：四个纯色全部互打和镜像共十六对、十二个双色阵容两两配对交换共十二对、四个三色分别对纯色并交换共八对。所有二十个阵容均有出现；不是二十乘二十的完整对局矩阵，各阵容的出场次数不相同，不能直接横向排颜色强弱。

三种固定种子覆盖延后部署三英雄的选择。塔攻击取 0／4／5／6，基地对应 0／8／10／12，保护仇恨开／关，共八场景。每场景 36×3＝108 局，合计 **864 局**。同一阵容、种子的初始牌序和环境随机流固定，所有场景共用同一 AI 和卡牌数值。

## 初步结果应怎样看

后续已复查 164 局超时样本并延长至 48 轮，见[超时与保护机制复查](timeout-review.md)。保护开关的完成局数排序在延长后反转，不能仅凭本页的 24 轮统计建议关闭保护。

每种场景都实际发生了基地被摧毁的胜负，十二种普通牌和十二种物品在批量样本中均有使用记录。规则检查、抽牌、召唤、装备、消耗品和金币消费已能连成完整流程。

但超时比例仍高：无攻击且无保护的场景为 43／108；塔五、基地十时，不开保护是 56／108，开保护是 60／108。已完成局的平均长度约十六到十七轮，**不能把它说成全部对局平均十七轮**。

塔五、基地十开保护时，十二个镜像样本全部超时，九十六个非镜像里四十八个超时。因此拖延不全来自镜像，也不能只归因于塔：塔无攻击时已经存在大量超时。牌库在中期耗尽、持续出兵与复活续航、当前 AI 缺乏协同推进都需要继续区分。

这批数据支持“最小内容已可测试”和“塔攻击／保护规则实际影响了对局”，尚不足以选定最优塔伤害或认定保护规则一定更好。累计金币消费包含更长对局的额外时间，不能直接当作单位回合经济效率。
