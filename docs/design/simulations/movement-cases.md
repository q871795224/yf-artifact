# 跟进与争格：三个独立局部样本

本页补充六回合开局没有触发的移动问题。坐标与开局样本相同：行 1–8、列 1–6，A 向上、B 向下。不是完整移动算法或随机概率测试。

## 连续跟进

初始坐标：A=(6,3)，B=(7,3)。

结果坐标：A=(5,3)，B=(6,3)。

A 先前进一步，B 跟进腾出的格子，各走一格。

## 己方争同格

初始坐标：A=(6,2)，B=(6,4)，H1=(5,1)，H2=(5,2)，H3=(5,4)，守兵=(5,5)，敌兵=(4,5)。

结果坐标：A=(5,3)，B=(6,4)，H1=(5,1)，H2=(5,2)，H3=(5,4)，守兵=(5,5)，敌兵=(4,5)。

守兵与敌兵接敌不移动。A、B 只有中间同一空格可走；事先给定本次随机样本 A 赢，B 留原位，不因先遍历左侧就固定判 A 赢。

## 双方争同格

初始坐标：A=(5,3)，B=(3,3)。

结果坐标：A=(5,3)，B=(4,3)。

两方同时想进入第 4 行第 3 列；事先给定本次随机样本 B 赢，A 留原位，随后两兵相邻可交战，不发生重叠或交换穿越。

已逐项检查三个结果没有重复占格、没有单位一步跨两格。两次争格的获胜者是明确指定的随机样本，不是执行随机抽样，也不能用于推导左右或阵营胜率。

这些样本支持把“前后跟进”和“同格随机裁决”分开处理。同排左到右只能是遍历顺序，不能自动决定争格结果。复杂绕行、依赖链及首次两格移动仍需单独细化。
