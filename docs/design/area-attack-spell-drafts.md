## 当前程序的攻塔与行军

以下为现有代码行为，不将新设计描述成已实装。

| 情况 | 当前行为 |
| --- | --- |
| 嘲讽／决斗锁定 | 本轮锁定存活敌方单位，不转去攻塔；超出射程也保留锁定，交战前按移动资格尝试追击 |
| 玩家主动指定敌军 | 本轮该敌军存活时保留目标，即使当前够不到，也不会转打塔；常规指令不能选择塔 |
| 普通自动索敌 | 在正交射程内选敌方单位；合法旧目标优先，否则选最近，同距按固定单位 ID；小兵另有保护己方英雄的转火规则 |
| 攻击塔 | 没有敌方单位仇恨目标、能攻击，并且与塔同行或同列且在自身普攻射程内时才攻击；普通近战射程 1，远程通常 2 |
| 塔伤 | 自身当前攻击力加攻城值；塔不会因为这次被打而立即反击，按正常交战结算塔炮 |
| 普通近战小兵行军 | 正四邻有敌人时停止。可以普攻敌塔时也停在原位，参与当轮交战 |
| 自动远程兵行军 | 在射程内可攻击单位或敌塔时停留 |
| 敌方泉水 | 非英雄单位的自动行军与仇恨追击均排除敌方泉水格。己方泉水仍用于出兵和返场 |

依据：[成长规则](../../scripts/growth_match.py)的 `aggro_target`、`target`、`building_target`、`stops_marching` 与 `combat`，[建筑射程](../../scripts/simulate_match.py)的 `building_target`，[行军](../../scripts/simulate_heroes.py)的 `auto_move`。普通自动索敌仅在射程内选单位，不将“场上还有一个敌人”误解为所有人都不能攻塔；主动指定或强制锁定可越射程保留是另一种情况。

2026-11-21 已补齐驻塔及敌方泉水的自动移动限制。小兵停在可攻击敌塔的格子，索敌继续先选合格敌军，再选塔。敌方泉水限制作用于自动行军和仇恨追击。强制位移仍按各自效果结算。

## 红色塔专用法术席位

用户担心红方难以接近塔时，专用攻塔牌无法发挥作用。该担心成立，新增红色法术第十二种不强制设计成只有塔旁可用的卡。

可继续讨论同时支持单位交战与攻塔的强化牌，例如基础加攻并附带攻城；也可以换成其他尚缺的用途。具体卡名、费用与效果均未确定。新命令等已有牌的改动也未获决定。红色应能攻塔的规范继续保留，不等于必须构筑一张塔专用牌。

## 红色 巨力挥舞

### 用户给定

2 法力，对正向及相邻敌人造成攻击力的伤害。占红色新增法术第十种，不新增数量。

### 卡文与范围建议

选择一名友方英雄与一个正四方向，对该英雄正前方一格及该格左右两格中的敌方单位，各造成等于该英雄当前攻击力的物理伤害。

本版将“正向及相邻”理解为前方一横排三格，仍待用户明确，不将其当成已经确认的唯一解释。向上释放示意：

```text
左  前  右
·   英  ·
```

建议采用以下结算：

- 选择英雄时读取当前总攻击力，包括装备、光环、永久与临时加攻、神之力量；各个目标分别扣护甲，不按攻击力造成无视护甲伤害。
- 这是法术造成的物理伤害，不是立即普攻，不额外触发分裂、电锤或受普攻触发的反伤。它与绿色选行法术承担不同任务。
- 对前方三格中的所有合格敌方单位生效，不要求中心格有敌人；边界之外忽略，不扩区补格。建议不伤建筑，保持塔伤由普通攻击及专门说明的效果承担。
- 使用普通法术的一次行动，不改变英雄的普通攻击目标，不消耗或刷新其本轮普通交战攻击。建议眩晕、妖术中的英雄不能作为挥舞执行者，沉默本身不禁止其执行非专属普通法术；不清除嘲讽或决斗。

伤害类型、执行英雄资格、三格范围及普攻附效资格均为助手建议；2 费和按攻击力伤害为用户方案。

例如英雄当前 4 攻，三格敌人护甲分别 0／1／2，则分别受到 4／3／2 点伤害。若神之力量使当前攻击为 8，同样目标受 8／7／6。2 费牌的上限由英雄强化与近身站位支持，神之力量组合可以保留为红色强势场景；当前未据此改费或声称已验证平衡。

## 绿色选行攻击法术

### 用户给定

5 法力，选定某一行为区域，所有能攻击该行敌人（包括塔）的友方单位，立刻施加一轮攻击。卡名未定，占绿色新增法术第十一种。

### 卡文与结算建议

选择战场一行。所有当前能攻击到该行合法敌方目标的友方单位，各立即进行一次普通攻击，目标可以是该行敌方单位或防御塔。不移动、不追击，不因法术增加射程。

本版按“一名友军最多一次攻击”解释，不将一轮攻击扩成对该行所有敌人逐一攻击；这个边界仍需用户明确。参与者可以站在其他行，只要按自身正交射程能打到目标；不是仅让选中行里的友军出手。

建议的目标与状态规则：

- 本次攻击将候选目标限定在所选行内；普通目标在行外，不阻止其在所选行寻找新目标。施放不永久改写原普通箭头。
- 强制锁定仍有效：嘲讽或决斗目标不在所选行或不在射程时，该单位不能借此攻击其他目标。眩晕、妖术禁止攻击；沉默不禁止普攻。
- 在该行内沿用普通索敌、保护转火及先单位后塔的思路。该行有可攻击单位时先打单位，没有时才攻击该行可触及的塔。不赋予塔优先。
- 建议先按施放时场面确定每名参与者的一个目标，再按一次同时攻击结算；不因前一名友军已击杀目标而自动将后一名攻击转移到塔或其他单位。

建议的攻击与回合规则：

- 使用当前攻击力、护甲、攻城及普攻附效；正常触发分裂、反伤和适用的装备攻击效果。主目标限所选行，正常分裂等附效范围不另外裁成一行。
- 敌方单位不因此获得一次额外普攻，塔也不额外开炮；受普攻反伤等正常响应仍结算。不是提前结束双方行动或提前执行完整交战。
- 本轮正常交战仍会攻击，不视为已经用掉回合末的攻击；这是一张以手牌、5 法力和场面条件换取额外攻击的牌。
- 不额外触发恢复、经验、回合末外壳或持续时间到期。整张法术全部结算后换手一次，若存在决斗，按已定换手规则触发一次互攻，不按参与友军数量反复触发。

以上为完整执行建议，未自动代替用户收口。它能清理拥挤的一行，也能在塔所在行制造额外塔伤。对手通过清场、控制与站位减少参与攻击的友军；空场或攻击不到目标时无法兑现收益，符合绿色依赖部队的方向。5 费先保留为用户初稿，不以最大塔伤算例直接宣布平衡或失衡。
