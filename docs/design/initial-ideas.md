# 初步玩法与讨论记录

更新日期：2026-11-16。

记录用户已确定的方向、最新提案和待讨论问题。助手的建议不自动成为游戏规则；举例数字不视为已定数值。已有脚本模拟及手机试玩版，可手动与 AI 完成一局；当前使用实验基准，不代表最终平衡。

## 手机界面方向（2026-11-16）

用户接受生成效果图的深色石板风格与区域占比，要求实际界面优先复用 Artifact 原版素材。采用完整 6×8 棋盘、头像棋子、选中单位操作条、普通牌／物品切换、底部双资源和让过按钮。已完成[手机战场试玩版](../../prototype/README.md)，复用现有推演引擎，提供固定阵容、固定牌池、交替行动、自动交战、返场与基地胜负，等待真实游玩反馈。用户同意先补操作细节、接通回合，再打通整局；未要求先扩充内容或重新开启大规模平衡实验。

## 产品方向

- 参考 Artifact，简化冗余和操作流程，面向轻量手机游玩。
- 供自己游玩，不商用。
- 设计类比为“中路大乱斗之于 Dota”。
- 不沿用此前助手提出的“所有操作都通过出牌”“装备与法术共用费用”“英雄阵亡不封锁颜色”等默认建议。

## 已确定：单路与英雄数量

- 从三路缩减为一路。
- 每方三名英雄，开局部署两名，第二回合部署第三名。
- 保留正常出兵；用户希望支持铺场与召唤流，若有单位上限，每方至少十个，十个不是已定上限。
- 满场时不再出兵，无法召唤新单位；只剩一个空位时如何处理一批多个单位、被阻止的出兵是否保留，待明确。
- 第一版双方每轮使用相同的出兵组合，部署位置随机。
- 每轮固定两个兵、近战／远程随机抽取仍为当前候选；具体概率及不同兵种的属性待定。

## 已确定方向：多排与兵线

- 用户担心手机竖屏无法横向摆下十个单位，提出整体 6×6 格的棋盘、横向最多六个单位对位。
- 战场六列八排，每方从中线向后有三排普通战场加一排泉水，一格一个单位，双方可以越过中线推进，也可进入敌方泉水。
- 塔保护区暂不设计具体保护效果，也不实装；保留后续扩展空间。
- 回合采用自动单位移动 → 出牌／技能／装备／英雄移动 → 交战的顺序。
- 首轮必须发生实际交战；后续每轮都有交战阶段，不交替设置纯赶路回合与战斗回合。个别单位仍需在射程内有合法目标才能攻击。
- 开局两名英雄与第一批小兵直接部署在中线附近，后续小兵、第三名英雄和复活英雄从泉水增援。首轮初始位置与箭头须满足实际交战要求，具体随机约束待定；不再全部从泉水赶路后第二轮才接战。
- 英雄移动改为出牌阶段的独立操作，与使用技能类似，占一次行动机会，随后由对手行动；不再单设双方交替移动英雄的阶段。
- 英雄和小兵的普通一步移动范围统一为周围八个相邻格，包含斜向、侧向与后方；不能移动到被占据的格子。此前确认的出生／复活后首次最多两格特例继续保留，每一步都检查占位。
- 小兵自动选择移动，召唤物按种类决定，英雄手动选择，每名英雄每轮移动一次；移动是否额外耗资源尚未单独明确。八方向是允许的步长范围，不代表小兵会主动随机后退。
- 自动小兵仍以向前推进为默认策略；前方被友军挡住时尝试侧前方，两侧都可用则随机，无路则停留，接敌停止推进，不直接跳到最前排。是否进一步主动侧移／后退属于行为规则，尚未另加。
- 允许跟进本批己方单位刚腾出的格子，后排仍只能按自己的移动步数前进，不获得额外步数。
- 自动移动按推进方向前到后处理跟进，不按出生时间。同排左到右可作为遍历顺序，但不能产生左侧争格固定优先权。
- 同批自动单位争同一空格时随机一个成功，其余原地停留；双方冲突共同处理，不先完整移动一方再移动另一方。首次两格拆为两次单格移动。完整依赖链、绕行与争格的衔接仍需细化。
- 近战一格、远程暂定两格以内，普通攻击一次只攻击一个目标，不因为射程内有多个敌人就同时攻击多个。
- 攻击箭头可朝上、下、左、右任一正方向，不含斜向；“前方”指箭头所指方向，不是固定朝敌方基地。近战攻击四个正向邻格之一，远程沿该方向直线攻击两格以内的一个目标；普通移动仍为八邻格。
- 单位不阻挡对建筑的攻击，射程内建筑仍为合法目标；同一攻击方向内，同时有合法敌方单位与建筑时优先攻击单位，没有合法单位目标时才攻击建筑。单位之间沿方向优先最近者；目标变化不重新抽方向。
- 需要共同决定移动时机、占位冲突、前排阻挡、后排近战能否攻击、箭头如何选择前后排目标，以及单位何时能攻击建筑。
- 六列六排是增加泉水前的基础布局；不采用此前的七个位置或双方合计四排的固定阵位方案。
- 详细规则及剩余待定项见 [战场与回合草案](combat-draft.md)。

## 已确定方向：出生区与泉水

- 英雄满场返场时允许替换一个己方非英雄单位；被替换者算死亡，正常向对方发放其死亡赏金。不能替换英雄或敌方单位。
- 常规增援与英雄复活默认在第四排泉水出现；开局首轮为满足立即交战需要单独设计初始部署。第三排出生作为以后节奏调整选项，第一版不并用第二排优先或第三排优先方案。卡牌召唤位置另定。
- 从中线向己方后方编号：第一排前排、第二排中排、第三排后排、第四排泉水；防御塔位于第三排与第四排之间，不占单位格。
- 泉水是实际参与战斗的额外区域，不是棋盘外预备区。其中单位可攻击、释放技能、提供光环，英雄可解锁对应出牌颜色。
- 敌人可以进入泉水并攻击其中单位，入侵者会受到泉水猛烈攻击；塔无论存活或摧毁均不阻挡通行，不能要求先破塔才能入泉。
- 每次出生／复活后的第一次移动最多两格，必须经过合法空格，不能跳过堵路单位；以后恢复正常步长，普通退回泉水不重置首次移动机会。
- 自动小兵的首次移动属于回合开始自动移动，英雄首次移动属于出牌阶段独立行动；出生当轮是否立即获得自动移动机会及两格移动的路径细则待定。
- 泉水攻击在交战阶段统一结算，并在出牌阶段展示可预见的伤害；一次攻击泉水范围内所有敌方单位，具体伤害待定，不按每次出牌反复触发，也不是攻击全棋盘敌人。
- 英雄留泉可作为后方指挥打法，仍然解锁颜色；普通攻击与局部技能／光环受其明确射程限制，全场效果需由具体能力说明。
- 第一版不额外加入泉水回血、刷新技能、复活加速或无敌机制。
- 出生区容量和满场规则、是否占单位上限、普通出兵与返场英雄的优先级也须明确，不能默认为无限囤兵。

## 已确定方向：双资源与装备手牌

- 水晶／法力与金币是两个独立资源。
- 普通卡牌使用水晶／法力，金币用于支付装备。
- 第一回合一个水晶，每回合增加一个，最高十个；具体刷新时机待明确。
- 保留增加水晶上限的法术方向；加速成长是否仍受十点上限约束待明确。
- 金币限制高价装备的使用时机，不能因为构筑时携带强力装备就过早打出。
- 普通手牌与装备手牌分区，装备按独立节奏发放，不占用普通抽牌机会；具体界面形式待定。
- 装备来自构筑时选入的装备卡，抽取时分为普通牌池与装备牌池。构筑界面可以统一选卡，具体交互待定。
- 装备先按开局一张，此后第三、六、九等回合各发一张。用户的“0、3、6、9”中零指开局发牌节点，不额外增加一个战斗回合。
- 装备携带总数、发放顺序是否随机、装备抽完后的处理待定；此前五张仅为示例。
- 已确定取消每轮工资，以敌方单位死亡赏金为常规金币来源。
- 自动出的小兵与卡牌召唤物各自拥有独立赏金数值；铺场单位死亡给对手金币是接受的取舍，不默认召唤物零赏金。
- 英雄死亡赏金、各种单位的赏金数值、初始金币与跨回合累计规则待定。
- 原版核对见 [原版与 Foundry 调研](../research/classic-foundry.md)。
- 装备手牌区与英雄身上的装备槽是不同概念；穿戴槽位、数量与替换规则待定。
- 当前方案不需要独立购物阶段；用户尚未明确购物阶段是否完全取消。

## 已确定：英雄操作与自动攻击

- 用户已确认改为自动索敌并保持合法目标；箭头展示攻击意图，普通攻击在交战阶段统一结算。此前随机箭头保留作对照。
- 不采用炉石式手动选择普通攻击目标、逐个操作英雄普攻的方式。
- 玩家通过出牌、英雄技能、穿戴装备与启动主动装备效果影响战场。
- 保留英雄主动技能与主动装备，增强操纵三名英雄的感觉；具体自身能力见[英雄草案](heroes-draft.md)，专属卡暂不制作，后续再讨论。
- 被动装备穿戴后提供属性或被动效果，无需额外启动；主动装备可以操作使用。
- 双方交替行动，每次可选择出一张牌、穿戴一件装备、使用一次英雄技能、启动一次主动装备或移动一名英雄，随后由对手行动。
- 双方连续让过后进入统一交战；下一轮先手、特殊额外行动及细节待定。
- 英雄主动技能不消耗水晶／法力，通过冷却限制使用；具体冷却长度与计时规则待定。
- 穿戴装备支付金币；装备主动效果通过冷却限制使用，不另收水晶或金币启动费用。
- 普通卡牌施放消耗水晶，金币用于装备穿戴；不增加独立的英雄行动资源。
- 出牌、穿戴装备、使用一次英雄技能或启动一次主动装备效果均占一次行动机会，完成后由对手行动。
- 具体冷却时长、登场／穿戴时是否可立即使用、冷却跨阵亡如何处理及特殊卡牌的额外限制尚未确定。

## 已明确：索敌、攻击意图与颜色限制

- 自动移动后公开目标，出牌阶段实际操作后刷新预览。普攻仍限定四正向，近战一格、远程两格。
- 英雄和小兵保持仍在合法射程内的旧目标；目标死亡、脱离射程或变成友军后，选最近合法敌人。首版同距离按稳定单位 ID 顺序选择。
- 箭头显示目标方向，不再随机选向，无目标则等待；索敌不自动追击，英雄移动仍为每轮一次的独立操作。
- 单位优先建筑的原则保留，当前脚本尚不模拟建筑。[4,800 局对照](simulations/hero-batch-02/README.md)另存，旧版样本保留作历史比较。
- 严格要求对应颜色的英雄在场，才能打出该颜色的牌。
- 某颜色英雄全部阵亡且无其他同色英雄在场时，不能打出该颜色的牌；不是任意一名英雄阵亡就封锁所有牌。
- 英雄阵亡后完整缺席下一回合，再下一回合返场。例如第二回合阵亡，第三回合不能登场，第四回合可以重新部署。
- 英雄死亡保留装备；满场返场允许替换己方非英雄单位，被替换者正常死亡并发赏金。生命恢复、冷却跨阵亡计时、全部英雄阵亡后的行动能力待明确。
- 装备是否无色、使用及主动效果是否受颜色限制，待定。

## 已确定方向：塔与基地

- 每方先有防御塔，防御塔摧毁后出现基地，基地摧毁即获胜。
- 用户最新修正：基地在塔被摧毁后出现于原塔相同位置，不在泉水后方；泉水是独立设施，不是必须摧毁的第三个建筑。塔不控制通行，先破塔再破基地，不能提前入泉跳过塔获胜。
- 平衡暂按：破塔过量伤害不转移给基地，基地下一回合开始承受伤害；破塔不额外奖励金币、强化兵或全队属性。
- 用户暂时接受上述缓冲方向，后续根据对局再调整，不额外加入补牌／补金币等守方补偿。
- 已接受塔四十血、基地八十血作为起点；基地与塔均为单目标攻击，基地攻击为塔两倍。塔无攻击与一击击杀原版基础兵的方向做对照；泉水攻击侵入范围内全部敌人。
- 保护仇恨作为候选对照：小兵八邻范围／建筑攻击范围内发现敌方英雄普攻友方英雄，且攻击者在合法普攻射程内，才转火；打不到则当无事发生，不追击。当前不实装护甲或减伤式塔保护效果。
- 本次[完整对局实验](simulations/match-batch-01/README.md)明确记录建筑射程、泉水伤害、抽牌、装备和同时破基地等测试假设，不自动将全部参数定为正式规则。

## 颜色数量与构筑讨论

- 沿用红、绿、蓝、黑四种颜色的方向。原版也是这四种颜色，不是五种，参考：[Artifact review](https://www.pcgamer.com/artifact-review/)。具体颜色卡池与英雄分配待设计。
- 在每名英雄一种颜色的前提下，三英雄可构成纯色、双色、三色队伍。
- 用户预期：纯色更稳定，多色的策略选择更灵活，双色可能是主流方向。这是玩法预期，尚非已验证的平衡结论。
- 三英雄的颜色分配为纯色 3、双色 2+1、三色 1+1+1；双色中单英雄提供的副色、三色中每一种颜色，都可能因一名英雄阵亡而被封锁。
- 第二回合才部署的英雄可能使某颜色在第一回合不可用，取决于开局两名英雄的选择。

## 优先继续讨论

### 2026-11-16：本轮优先验证双经济终端

- 用户明确选择先完善终结比赛的能力：高法力牌应能带来更强的终局影响，金币应能购买强力装备，由成型英雄兑现为击杀和推进；不同颜色可以有不同侧重。
- 后期成长希望进攻强于纯防御堆叠，向玻璃大炮倾斜，避免双方高防破不了防。尚未要求统一削弱所有生命／护甲装备，或取消红色英雄的扎实定位。
- 三回合一次购物、三选一作为后续机制方向讨论，本轮先从原版卡池选择终端测试，不将此前助手提出的每两轮发牌等建议自动实装。
