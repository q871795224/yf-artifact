# 试玩后的路线图

更新于 2026-11-17。V0.3 已发布，记录见[V0.3 归档](../releases/v0.3.md)；其后有未发布的界面微调和新 Demo 设计讨论，二者状态分开记录。这些试验仍需真人试玩，不表示已完成平衡或实体手机验收。

## 下一轮：渐进成长与简化卡牌

用户提出开局信息过多、英雄缺少从弱到强的过程、卡牌过于复杂，优先沿此方向讨论。收益兑现暂不列为已确认问题。完整结论、用户候选数值和未定项见[成长 Demo 记录](growth-demo.md)。

- 已确认方向：三级英雄＋装备双线成长；第一版只累计回合末存活的回合数，经验后置。
- 已同意试验：每方一个英雄和一个小兵开局，前三轮各登场一个英雄，第 2 轮起每轮补一个小兵；沿用卡面并增加等级／解锁提示。
- 内容收窄到原色不变的红／绿各三英雄，重做简单低费牌和装备。撼地者是蓝色，本轮排除，跳刀回音击连招暂缓。
- 当前只对齐英雄：斧王、军团的成长面板与专属卡为用户候选；嘲讽、反伤触发范围、即时／回合末交战以及斯温方案仍待确认。
- 未开始实现成长、新卡池或新经济，不把助手建议自动视为已确认规则。

## 同轮试验：布局与建筑

| 内容 | 已选择的方案 | 后续观察 |
| --- | --- | --- |
| 正方形格子 | 五列八排，按可用宽高缩放，矮屏收窄居中 | 实体手机可读性与点选 |
| 取消操作栏 | 单击英雄选移动，技能／装备位于棋子内，长按详情；保留取消入口 | 小屏按钮误触、可发现性、装备主动 |
| 塔／基地 | 泉水排中央占一格，两侧各留两格；泉水不作为受击对象 | 出生／返场拥堵、进攻路径、对局时长 |

两格建筑不在本轮实现。若后续试验，需要重新处理五列布局的对称性和仅剩三个出生格的容量问题。

## 后置：用户明确先不做

- 棋子在格内留白、扩大视觉间隙；当前继续铺满格子。
- 河流、树木与其他装饰。先确保不会误导通行和射程，再决定是否引入真实地形规则。
- 双击施法快捷方式；先观察显式技能按钮是否足够。
- 选英雄、构筑和三选一商店保留原待办。专属卡已进入新 Demo 的设计讨论，尚未实装，见[成长方案](growth-demo.md)。

建筑位置变化后，应基于新地图重新观察拥堵和推进，不直接沿用六列或旧非占格模型的平衡结论。

## V0.3 追加试玩反馈：核心乐趣待验证（2026-11-17）

用户简单游玩后反馈“感觉不到乐趣”，原因尚未确认；不能将其直接解释为不熟悉英雄／卡牌，也不能把自动对局能结束当作真人体验已通过。

- 展示微调已在源码完成、尚未发布：预计阵亡红叉降至 55% 不透明度；去掉手牌上方重复的我方建筑／回合状态行。我方建筑血量仍在棋盘上，回合与阶段移入对局菜单；选目标提示临时覆盖手牌上沿，保留取消按钮，不遮挡棋盘落点。验证见[未发布记录](../../CHANGELOG.md)。
- 早期假设包括固定首发主动操作较少、收益兑现间隔、返场行军与重复换兵、固定牌库缺乏期待，均未被试玩证实。用户后来认为收益兑现还好，并将讨论重点转向渐进成长和简单卡牌。
- “少量已讲清作用的牌＋三至五回合局部目标”保留为助手提出的诊断方法，尚未实施，不替代上方新 Demo 方向。
- 当前战斗引擎没有改阵容、卡牌数值、资源、移动、索敌或交战规则。
