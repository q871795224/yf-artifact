# V0.4 发布与验证归档

2026-11-18，源码标签 `v0.4`。用户已授权推送 GitHub 并发布静态网站。公开核验将在 Pages 部署完成后追加。

## 内容

- 六位红绿英雄三级成长、回合经验、分批入场与六种专属解锁；所有专属都要求对应英雄在场且达到等级。
- 12 种普通单位、19 种普通法术、18 件装备及 4 种消耗品。
- 30 张普通牌（9 专属＋21 自选）、10 张物品牌，同名最多3张；菜单构筑保存后用于下一局。
- 普通牌重铸，先抽后归库，1行动、0法力；物品不可重铸。普通仇恨与锁定仇恨共用交战前追击，普通箭头可覆盖。
- HTTP 与浏览器 Python Worker 共用规则，回放包含构筑；沉默、妖术、BKB、圣剑等按统一结算实现。

完整规则和边界见[实现说明](../design/growth-implementation.md)，历史讨论见[设计记录](../design/growth-demo.md)。

## 发布前验证

- 166 项 Python 自动测试通过，包括历史实验回归、新规则、构筑、传输、静态构建及确定性重放。
- 界面、特效、客户端及浏览器检查脚本通过 Node 语法检查，`git diff --check` 通过。
- HTTP 与静态 Worker 各通过20项浏览器操作检查，覆盖三种视口、构筑、重铸、增援、经验、移动、刷新恢复、成长详情和图片加载，无 JavaScript 运行错误。脚本为 `scripts/check_growth_prototype.js`。
- 额外检查1017个合法行动，覆盖全部37种普通单位／法术／专属；执行后位置、生命及容量约束通过。
- 静态站点构建成功，Pages 只包含白名单文件，不含工作台、原始 PNG、临时输出或玩家存档。

## 局限

实体手机与真人平衡尚待试玩。六种子 AI 自对局中四局在36～90轮结束，两局观察到120轮仍无胜负；不设置人为回合上限判输赢。这些结果不能作为真人胜率或平衡结论。

V0.3 旧规则存档不能迁移到本版，需开始新局；同版本内支持刷新恢复。
