# V0.3 发布与验证归档

发布日期：2026-11-17，源码标签 `v0.3`。本页保留本地验证与上线核验记录，平衡和实体手机体验继续交由试玩判断。

## 局限

- 桌面 Chrome 的手机视口模拟不替代实体手机验证，长按、28px 棋子内按钮与矮屏收窄需要真人试玩。
- 素材库远程索引不等于已缓存客户端全量资源，旧 CDN 链接可能失效。用户提供的夜魇近战兵已经替换敌方基础近战兵外观，远程小兵仍未实现。
- 源码构建会生成新的引擎指纹，旧规则浏览器存档不能直接恢复为新地图。
