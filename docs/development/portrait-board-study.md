# Artifact 竖屏棋盘试作复盘

2026-11-24。我们在 PC 上用 Godot 验证了手机比例下的一条战线。可沿用的基线是天辉在上、夜魇在下，中央保留河缝，两侧共用五列、八行棋位。玩家已认可两端补洞、收边和棋位布局；最后一轮木纹已完成实机对照，仍待审美确认。浏览器试玩和手机端的发布状态不受本轮实验影响。

## 下次改棋盘时从哪里起步

| 项目 | 本轮保留的做法 | 选择依据 |
| --- | --- | --- |
| 原始模型 | 单独使用 Classic 中路棋盘，移除另外两路和外围蜡烛，保留阵营端景、侧框及河道几何 | 三条路同时进入竖屏时，棋位和边景挤在一起。原版端景能让人一眼辨认阵营方向 |
| 镜头 | 1260 × 2800 竖屏画布，桌面验证窗口 540 × 1200。透视相机从夜魇端向下看，仰角参数为相对水平面 62° | 斜视保留塔的正面和棋盘厚度。此前 80% 俯视、145% 缩放是试验值；默认进入整盘，滚轮缩放和拖动用于看细节 |
| 棋位 | 河缝两侧各四行，五列共用同一条中轴。方形卡图填满棋位，空位只画角标。两塔放在各自外侧数第二行的中列 | 以河缝和木板端线确定首末行，再均分行距。把卡面高度降到接近桌面后，斜视下靠近下端的一排也能准确落位 |
| 端景 | 两端各填圆形按钮槽、中央旧塔座和矩形牌堆槽。天辉用草坡及原版树冠中的枝叶，夜魇用原版岩石材质和高低错落的岩块 | 同一个槽形放在不同阵营需要不同的地形。靠棋盘的一侧可以齐，背向棋盘的一侧保留起伏 |
| 河与木板 | 河道保留原形，水面使用低对比的静态材质。延长可落子的木板，木纹按模型空间距离取样，在河岸和侧框附近渐变回原贴图 | 原版截图里的河很窄，强水纹会抢走卡面的注意力。固定木纹尺度后，继续改棋盘长度也不必重新拉伸纹理 |

## 遇到的问题与解决办法

| 看见的症状 | 原因与处理 | 复查位置 |
| --- | --- | --- |
| 延长棋盘后，树、石头和侧边竖件一起变形或反复出现 | 拆分连续的木台、结构边框和刚性摆件。延长木台，整体平移摆件，侧框只补缺少的那一段 | 同一机位看两端树冠宽度，再沿两侧检查有无重复的竖件 |
| 旧塔座补成一块暗矩形；扩大裁切后又丢了边景 | 平铺颜色只能挡住洞口，覆盖范围过大会吃掉原生地形。用 Blender 沿每个槽口单独建低矮曲面，使用邻近地表的色调、枝叶和岩石轮廓过渡。原模型保留，方便原位切换 | 固定镜头按 P 对照，放大看前沿、左右接缝和后坡，再退回整盘看是否仍像一块补丁 |
| 洞补上了，牌堆槽和旧塔座仍伸进棋位 | 同时裁掉补面和原槽朝向木板的凸出部分。用原木面几何续到裁线，并给剖面加窄边。第一次裁切出现黑缝，排查发现重建后表面序号已变，改按材质名识别木面 | 检查两端直边全长，特别是木面与侧框相交的四角 |
| 上下棋位看似不正，夜魇一端留白偏大 | 撤掉单阵营额外的纵向偏移，两端按相同的物理边距排布。卡图、角标和塔使用同一格心 | 用整盘同时看河边首排、中列塔和两端末排。透视会使近端格子显得更大 |
| 木纹被拖宽，重新铺纹后又出现黑三角和深浅条带 | 拉长网格时原 UV 把纹理和烘焙阴影一起拉长。新材质从原图集的净木面取样，避开带槽口阴影的区域；逐板错开采样位置，并校正各段平均亮度。原色图与法线图按同一坐标读取 | 同机位比较一块空棋位宽度里的纹路，再看河边过渡、板缝和端线有无接痕 |
| 静态预览也使机器负载升高 | 预览启用 Godot 低处理器模式，静止时减少重绘。运行日志显示本次环境使用 Mesa llvmpipe 软件渲染，风扇声不足以判断独显负载 | 分别观测静止和拖动时的开销，记录渲染设备。手机帧率、显存和功耗仍需真机验证 |

## 本机复查

保留试作目录的工作站可在仓库根目录运行下列命令。工程、原版导出资产和截图位于本地的 `output/research/artifact-classic-radiant-inlay/`。仅克隆仓库时，这个目录需要另行准备。验证环境为 Godot 4.7.1 和 Blender 4.5.16。

```bash
board=output/research/artifact-classic-radiant-inlay
godot --path "$board" --rendering-method gl_compatibility
godot --path "$board" --rendering-method gl_compatibility -- --capture
```

交互窗口里，滚轮围绕光标缩放，左键拖动画面，端景按钮切换到两端，按 0 回到整盘。自动截图需在有显示服务的环境中运行。检查进程退出码和 Godot 日志中的脚本或着色器错误，再看这些画面：

- `radiant-garden-board.png` 用于看整盘朝向、河缝、棋位对齐和近端留白。
- `radiant-garden-detail.png` 与 `dire-inlays-detail.png` 用于核对两端切面。对应的 `*-original.png` 是同机位关闭补洞的画面。
- `wood-comparison.png` 是本轮另存的固定机位裁图，左旧右新。后续做材质对比时，先留存旧截图，再运行捕获，以免基线被覆盖。

## 留给下一轮的决定

先用同一机位评价木纹是否抢过卡图，以及细板缝是否容易与棋位角标混淆。棋子薄边、受光上沿和接触阴影是候选实验，尚未实施。若决定继续，先只改河边一枚，让相邻四枚充当现场对照，再决定是否推广全盘。
