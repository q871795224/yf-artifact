# 原版美术素材：首批本地缓存

下载日期：2026-11-16。来自本地 `../cards.json` 保存的 Valve CDN 图片地址，文件保持下载原样；不包含客户端完整资源。

当前选择覆盖十二名候选英雄、三份候选牌池的并集、基础近战兵、防御塔与遗迹塔，以及这些记录引用的技能和衍生单位。英雄专属卡未额外纳入。共选择 72 条记录，其中 59 条具有图片，实际下载 **130 张，43,018,613 字节（约 41 MiB）**，下载失败 0。

## 文件用途

| 目录 | 数量 | 用法与实际抽查 |
| --- | ---: | --- |
| `mini_image/` | 59 | 267×267 的方形缩略图；斧王为原版绘画头像，适合手机棋盘单位及卡牌缩略展示 |
| `large_image/` | 59 | 优先下载简体中文完整卡面，当前均为中文；包含原版卡框、费用、正文或数值，不是无字原画 |
| `ingame_image/` | 12 | 十二名英雄的局内小图标；斧王抽查为像素风角色标识，不能按字段名误认为完整英雄立绘 |

文件以官方卡牌 ID 命名，例如 [斧王头像](mini_image/10020.png)、[斧王中文卡面](large_image/10020.png)、[斧王局内图标](ingame_image/10020.png)。

[manifest.json](manifest.json) 逐张记录名称、ID、类型、语言、原始 URL、本地相对路径、尺寸、大小与 SHA-256。`missing_image_fields` 表示原索引未提供相应图片字段，常见于技能记录，不是下载失败。后续新增素材应保留同样的来源记录。

## 手机界面的使用方向

用户已接受生成效果图的整体气质与区域占比：深色石板战场、完整 6×8 棋盘、英雄头像棋子、选中单位操作条、底部普通牌／物品切换、双资源及让过按钮。实际画面优先复用 Artifact 原版素材。

- 棋子优先使用 `mini_image`，其外框、当前攻血、颜色及状态由界面绘制。
- 原版完整卡面供查阅和视觉参考；本作修改过的费用、技能、正文与当前数值由自己的界面显示，避免显示成原版规则。
- 当前没有单独下载无字原画。需要更大面积插画时，先从客户端查找对应原画资源，再决定是否使用现有卡面的插画区域。
- 卡框、通用攻防血／金币／法力图标、按钮、棋盘材质、音效尚未提取，当前缓存不代表这些资源已经齐备。

## 客户端资源的下一条路径

本机默认 `/Applications/Steam.app` 与 `~/Library/Application Support/Steam/steamapps` 路径下未发现 Steam；尚未定位到可供提取的 Artifact 客户端文件，不排除安装在其他位置。

[Source 2 Viewer](https://s2v.app/) 支持读取 VPK、提取资源及将纹理导出为 PNG，并提供 macOS Apple Silicon 命令行版本。找到客户端后，可以先浏览目录并导出少量 UI 图标／卡框作验证，再按手机原型需要补充资源。工具可行性已查证；本项目尚未执行客户端 VPK 提取。

Valve [官方 API 说明](https://github.com/ValveSoftware/ArtifactDeckCode#card-set-api) 说明了 `mini_image`、`large_image` 与 `ingame_image` 等字段。历史 API 索引的来源及版本见[参考库说明](../README.md)。素材归属沿用参考库记录。
